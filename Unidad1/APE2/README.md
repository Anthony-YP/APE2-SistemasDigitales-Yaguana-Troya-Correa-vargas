# APE2 - Unidad 1: Juego de luces interactivo con ESP32

## Descripción del proyecto

Este proyecto corresponde a la Práctica N.º 2 de la asignatura **Sistemas Digitales**, de la carrera de Computación de la FEIRNNR.

Consiste en el diseño, programación y prueba de un juego de luces interactivo utilizando la placa **ESP32 DevKit V1**. El sistema controla una secuencia de cuatro LED y permite modificar su velocidad mediante un pulsador.

La práctica se desarrolla en dos etapas de programación: una secuencia básica de iluminación con temporización configurable y una versión interactiva que incorpora detección de pulsaciones, antirrebote por software y visualización del período en el Monitor Serie. El circuito se prueba tanto en el simulador Wokwi como con la placa física.

## Objetivos

- Programar un juego de luces con cuatro LED utilizando el microcontrolador ESP32.
- Implementar temporización no bloqueante mediante la función `millis()`.
- Controlar la velocidad de la secuencia mediante un pulsador con resistencia pull-up interna.
- Aplicar técnicas de antirrebote por software y detección de flanco para registrar correctamente las pulsaciones.
- Verificar el funcionamiento del circuito mediante simulación en Wokwi y pruebas con el hardware real.
